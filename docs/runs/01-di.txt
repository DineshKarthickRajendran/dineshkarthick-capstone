Dependency injection in FastAPI is a design pattern used to manage dependencies in your application. It allows you to define how components (like services, databases, or configurations) are provided to your route handlers or other components, promoting modularity and testability.

In FastAPI, you can declare dependencies using the `Depends` function. This allows you to specify functions or classes that should be called to provide the necessary dependencies for your endpoint functions. FastAPI automatically resolves these dependencies when handling requests.

### Example:

```python
from fastapi import FastAPI, Depends

app = FastAPI()

def get_query_param(q: str = None):
    return q

@app.get("/items/")
async def read_items(query: str = Depends(get_query_param)):
    return {"query": query}
```

In this example, the `get_query_param` function is a dependency that retrieves a query parameter. The `Depends` function tells FastAPI to call `get_query_param` and pass its return value to the `read_items` function. This makes it easy to manage and reuse dependencies across different endpoints.
